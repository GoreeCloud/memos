## Product Overview

**GoreeCloud Memos** is envisioned as a private-first, self-hostable, cross-platform note-taking and productivity application that brings quick capture, rich writing, media, reminders, collaboration, and personal information organization into one cohesive experience.

The product should maintain a fast, lightweight core experience while making advanced capabilities available when needed.

The following catalog represents the combined target feature set. It is not a statement that every capability has already been implemented.

## Product Direction

**GoreeCloud Memos should retain instant capture, simplicity, self-hosting, portability, and private-first operation as its foundation.**

The expanded feature vision can be implemented through progressively disclosed capabilities—quick capture first, advanced tools when requested—rather than requiring every user to navigate a complex document-management interface.

A key architectural decision remains whether all advanced features should belong in GoreeCloud Memos or whether the existing separation between GoreeCloud Memos and GoreeCloud Notes should remain.

**Target outcome:** A cohesive GoreeCloud note-taking experience that combines fast capture, organization, Markdown portability, rich content, media, reminders, collaboration, accessibility, and user-controlled data without making cloud hosting, telemetry, or external AI mandatory.
