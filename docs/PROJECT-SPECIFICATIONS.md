# GoreeCloud Memos — Project Specifications

## Product role

GoreeCloud Memos is the GoreeCloud quick-capture notes product. It is intentionally lighter than GoreeCloud Notes: fast entry, Markdown, tags, search, spaces, attachments, archive, and portable data are primary; deep knowledge-management workflows belong in GoreeCloud Notes.

## Development path

**Maintained Fork.** The project is based on `usememos/memos` and may remain fork-derived as long as the architecture stays maintainable, license-compatible, secure, privacy-compatible, and meaningfully GoreeCloud-controlled.

Superficial rebranding is not sufficient. GoreeCloud owns the derivative product experience, privacy defaults, security posture, Glaze layer, ecosystem contracts, release evidence, update policy, and operational responsibility.

## Required product properties

1. Private-first self-hosting and least-privilege defaults.
2. Individual accounts and explicit authorization boundaries.
3. Fast quick-capture composition with Markdown portability.
4. Search, tags, spaces, archive, attachments, and recoverable user workflows.
5. Export/import and documented backup/restore.
6. No required telemetry, advertising, proprietary hosted control plane, or third-party AI service for core operation.
7. Responsive, keyboard-accessible, screen-reader-compatible, reduced-motion, reduced-transparency, high-contrast, and RTL-capable presentation.
8. Current Glaze consumer target with product-local acceptance.
9. Explicit upstream provenance, update review, security-patch intake, and regression testing.
10. Evaluation and evidence for all nine Integral Platform Systems.

## Stable boundary

Upstream maturity does not make this fork Stable. Production/Stable claims require current GoreeCloud security, privacy, accessibility, recovery, performance, platform integration, release, and production acceptance evidence.
Demo mode is an explicit public demonstration exception intended for synthetic/demo content; it must not be used as the deployment mode for private user data.
